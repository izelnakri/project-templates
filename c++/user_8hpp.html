Detailed Description

Defines the User class for representing and retrieving GitHub user data.

The User class encapsulates GitHub user information such as login, name, company, and location. It provides functionality to print this data and to fetch a user's information from the GitHub API over HTTPS using Boost.Asio and Boost.Beast.
