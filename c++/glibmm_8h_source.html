22/** @mainpage glibmm Reference Manual
23 *
24 * @section description Description
25 *
26 * glibmm is the official C++ interface for the popular cross-platform library %Glib.
27 * It provides non-UI API that is not available in standard C++ and makes it
28 * possible for gtkmm to wrap GObject-based APIs.
29 * See also the <a href="https://gnome.pages.gitlab.gnome.org/gtkmm-documentation/">
30 * Programming with gtkmm</a> book for a tutorial on programming with gtkmm and
31 * glibmm.
32 *
33 * @section features Features
34 *
35 * - Glib::ustring: A UTF-8 string class that can be used interchangably with std::string.
36 * Plus @ref StringUtils
37 * - Glib::RefPtr: A reference-counting smartpointer, for use with Glib::ObjectBase or similar
38 * - @ref CharsetConv
39 * - Glib::Regex: Regular expression string matching.
40 * - Glib::KeyFile: Parsing and writing of key files (similar to .ini files)
41 * - Glib::Checksum
42 * - Glib::Date, Glib::DateTime, Glib::Timer
43 * - Glib::Dispatcher: Inter-thread communication
44 * - @ref FileUtils and @ref UriUtils
45 * - @ref MainLoop
46 * - @ref Spawn
47 * - @ref MiscUtils
48 *
49 * giomm (part of the glibmm project) also contains:
50 * - Asynchronous IO. See Gio::File and the @ref Streams.
51 * - @ref NetworkIO
52 * - @ref DBus
53 * - Gio::Settings for application settings.
54 *
55 * @section basics Basic Usage
56 *
57 * Include the glibmm header, plus giomm if necessary:
58 * @code
59 * #include <glibmm.h>
60 * #include <giomm.h>
61 * @endcode
62 * (You may include individual headers, such as @c glibmm/ustring.h instead.)
63 *
64 * If your source file is @c program.cc, you can compile it with:
65 * @code
66 * g++ program.cc -o program `pkg-config --cflags --libs glibmm-2.68 giomm-2.68`
67 * @endcode
68 * If your version of g++ is not C++17-compliant by default,
69 * add the @c -std=c++17 option.
70 *
71 * If you use <a href="https://mesonbuild.com/">Meson</a>, include the following
72 * in @c meson.build:
73 * @code
74 * glibmm_dep = dependency('glibmm-2.68')
75 * giomm_dep = dependency('giomm-2.68')
76 * program_name = 'program'
77 * cpp_sources = [ 'program.cc' ]
78 * executable(program_name,
79 * cpp_sources,
80 * dependencies: [ glibmm_dep, giomm_dep ]
81 * )
82 * @endcode
83 *
84 * Alternatively, if using autoconf, use the following in @c configure.ac:
85 * @code
86 * PKG_CHECK_MODULES([GLIBMM], [glibmm-2.68 giomm-2.68])
87 * @endcode
88 * Then use the generated @c GLIBMM_CFLAGS and @c GLIBMM_LIBS variables in the
89 * project Makefile.am files. For example:
90 * @code
91 * program_CPPFLAGS = $(GLIBMM_CFLAGS)
92 * program_LDADD = $(GLIBMM_LIBS)
93 * @endcode
94 */
